
# 🍔 Food Chef – Food Ordering Website

Food Chef is a responsive food ordering website built using HTML, CSS and JavaScript.

## Features
- Professional restaurant website design
- Chef hat logo and Food Chef branding
- Food menu with images
- Search food items
- Filter by food category
- Add to cart
- Increase and decrease item quantity
- Automatic cart total calculation
- Tamil Nadu delivery address form
- Responsive layout for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript
